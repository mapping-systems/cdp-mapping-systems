# Micro-Refuge — Final Project v9

This package contains the two active parts of the project:

1. `analysis/` — Jupyter Notebook computation and data pipeline.
2. `web/` — interactive English web-map application.

Both now use the same white-background visual system: black/gray urban base, deep/light greens as the primary analytical colors, yellow/lime for the remaining visual conditions, and blue only for interaction/method markers.

Run the notebook from inside the `analysis/` folder so its relative `data/` and `outputs/` paths resolve correctly.
