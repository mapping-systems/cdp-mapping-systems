# Assignment 03 — The Museum Is Not One Place

## Live-map concept

**The Museum Is Not One Place** visualizes the distributed network
infrastructure encountered during one visit to The Metropolitan Museum
of Art website.

The HAR file contains 600 browser requests across 52 domains and 49
unique public server IPs. The map uses the GeoJSON generated by the
course HAR-geolocation script.

## How the map works

- Circle size represents the number of HAR requests associated with an IP.
- Circle color distinguishes:
  - The Met first-party services
  - analytics
  - advertising
  - social/tracking services
  - infrastructure and other services
- Cluster circles group IPs with overlapping approximate locations.
- Clicking a server point opens a popup containing its IP, service
  category, organization, location, request count, domains, and a
  representative URL.
- A black marker shows The Met's physical location.
- Faint red lines connect the physical museum to the servers involved in
  the browsing session. These are conceptual dependency lines rather
  than measured network routes.

## Method

1. Record a browsing session on `metmuseum.org` using Chrome DevTools.
2. Export the Network log as a HAR file.
3. Extract unique public server IPs from the HAR.
4. Geolocate the IPs using approximate IP-geolocation services.
5. Export the results as GeoJSON.
6. Load the static GeoJSON into MapLibre as an interactive point layer.

## Limitations

IP geolocation is approximate and often returns a corporate or regional
network location rather than the precise physical server. Multiple IPs
may be assigned the same generalized city coordinate. The map also
represents one browsing session and does not show the complete or
permanent infrastructure of The Met website.

Connection lines do not show packet routes or data transmission paths.
They only indicate that each server IP participated in the captured
session.

## Run locally

Open the folder in VS Code and use **Open with Live Server** on
`index.html`.

Opening `index.html` directly from the file system may prevent the
browser from loading the local GeoJSON because of browser security
restrictions.
