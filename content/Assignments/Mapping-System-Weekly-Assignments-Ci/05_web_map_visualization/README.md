# 05 — Web Map Visualization

## Rent Growth Within Reach

**Research question:** How can a web map show both the ten-year change in
Manhattan median asking rent and the distance between a user-selected point and
nearby rent-reporting areas?

This assignment translates the course restaurant-and-distance example into a
housing question. A MapLibre interface queries 31 Manhattan StreetEasy
rent-reporting points through a Supabase/PostGIS spatial function. The same page
can also calculate results from a committed GeoJSON file, so the visualization
remains usable when the API is unavailable.

The complete implementation is split into the same core files introduced in
the course web-mapping tutorial:

**[Open the live Supabase/MapLibre result on GitHub Pages](https://cisanotheraccount.github.io/cdp-mapping-systems_Ci/content/Assignments/Mapping-System-Weekly-Assignments-Ci/05_web_map_visualization/)**

1. [`index.html`](index.html) defines the interface and loads the map.
2. [`style.css`](style.css) controls the desktop and mobile layout.
3. [`map.js`](map.js) loads the data, queries distance and draws the results.
4. [`config.example.js`](config.example.js) documents the browser-safe API
   configuration.
5. [`sql/setup.sql`](sql/setup.sql) creates the PostGIS table, read policy and
   radius function; [`sql/seed.sql`](sql/seed.sql) supplies the 31 fixed rows.

The [live Supabase/PostGIS map](https://cisanotheraccount.github.io/cdp-mapping-systems_Ci/content/Assignments/Mapping-System-Weekly-Assignments-Ci/05_web_map_visualization/)

## 2. Encode rent and distance

The map deliberately separates three variables:

- **Color** encodes nominal percentage change in median asking rent from July
  2016 to June 2026.
- **Circle size** encodes June 2026 median asking rent.
- **Connecting lines, labels and result order** communicate geodesic distance
  from the user-selected point.

MapLibre expressions apply the same encodings to the contextual points and the
filtered results. This is the highlighted-result layer from
[`map.js`](map.js):

```javascript
map.addLayer({
  id: "rent-results",
  type: "circle",
  source: "rent-areas",
  filter: ["in", ["get", "area_id"], ["literal", []]],
  paint: {
    "circle-color": ["interpolate", ["linear"], ["get", "growth_pct"], 20, "#f5dfb1", 35, "#efb366", 50, "#e56c3d", 70, "#9e2f27"],
    "circle-radius": ["interpolate", ["linear"], ["get", "latest_rent_usd"], 2500, 7, 6000, 15],
    "circle-opacity": 0.92,
    "circle-stroke-color": "#172029",
    "circle-stroke-width": 1.3,
  },
});
```

Clicking the map updates the selected coordinates and query. Clicking a result
centers that area and opens a popup with its July 2016 rent, June 2026 rent,
nominal growth and distance.

## 3. Query Supabase and PostGIS

The browser sends the selected latitude, longitude and radius to one read-only
RPC. Only the public publishable/anonymous key is used; no `service_role` key
belongs in browser code. The request in [`map.js`](map.js) is:

```javascript
async function apiQuery(point, radiusMeters) {
  const config = window.RENT_MAP_CONFIG;
  const response = await fetch(`${config.SUPABASE_URL}/rest/v1/rpc/find_rent_areas_within_radius`, {
    method: "POST",
    headers: {
      apikey: config.SUPABASE_ANON_KEY,
      Authorization: `Bearer ${config.SUPABASE_ANON_KEY}`,
      "Content-Type": "application/json",
    },
    body: JSON.stringify({ lat: point[1], lon: point[0], radius_m: Math.round(radiusMeters) }),
  });
  if (!response.ok) throw new Error(`Supabase RPC returned HTTP ${response.status}`);
  return response.json();
}
```

On the database side, PostGIS performs a geography-based radius filter and
returns the actual distance in meters. The full schema, GiST index, row-level
security policy and function privileges are in [`sql/setup.sql`](sql/setup.sql).
The central spatial section is:

```sql
select
    p.area_id,
    p.area_name,
    p.baseline_rent_usd,
    p.latest_rent_usd,
    p.rent_change_usd,
    p.growth_pct,
    p.longitude,
    p.latitude,
    gis.st_distance(
        p.geometry,
        gis.st_setsrid(gis.st_makepoint(lon, lat), 4326)::gis.geography
    ) as distance_m
from public.rent_growth_points as p
where radius_m between 100 and 20000
  and gis.st_dwithin(
      p.geometry,
      gis.st_setsrid(gis.st_makepoint(lon, lat), 4326)::gis.geography,
      radius_m
  )
order by p.geometry operator(gis.<->)
    gis.st_setsrid(gis.st_makepoint(lon, lat), 4326)::gis.geography;
```

The table grants anonymous users `SELECT` and RPC execution only. Anonymous
`INSERT`, `UPDATE` and `DELETE` privileges are revoked.

## 4. Preserve a local fallback

The page loads
[`data/manhattan_rent_growth_points.geojson`](data/manhattan_rent_growth_points.geojson)
before running either query path. If no Supabase configuration is present—or
if the live request fails—the browser measures Haversine distance against that
local file, applies the same radius and sorts the rows by distance:

```javascript
function localQuery(point, radiusMeters) {
  return state.localData.features
    .map((feature) => {
      const distanceMeters = haversineMeters(point, feature.geometry.coordinates);
      return {
        ...feature.properties,
        longitude: feature.geometry.coordinates[0],
        latitude: feature.geometry.coordinates[1],
        distance_m: distanceMeters,
      };
    })
    .filter((row) => row.distance_m <= radiusMeters)
    .sort((a, b) => a.distance_m - b.distance_m);
}
```

The mode selection is explicit in the application logic:

```javascript
if (hasSupabaseConfig()) {
  try {
    results = await apiQuery(state.selectedPoint, radiusMeters);
    state.mode = "api";
  } catch (error) {
    console.warn("Supabase unavailable; using local fallback.", error);
    results = localQuery(state.selectedPoint, radiusMeters);
    state.mode = "local";
  }
} else {
  results = localQuery(state.selectedPoint, radiusMeters);
  state.mode = "local";
}
```

This fallback is not a second dataset. Both modes use the same 31 reporting
points and the same frozen July 2016–June 2026 values; only the place where the
distance calculation runs changes.

## 5. Run the project

From the `Mapping-System-Weekly-Assignments-Ci` project folder, start a static
server:

```bash
python -m http.server 8005
```

Then open `http://localhost:8005/05_web_map_visualization/`. A server is needed
because the browser fetches local GeoJSON; opening `index.html` as a `file://`
URL may block those requests.

To reproduce the live database mode:

1. Run [`sql/setup.sql`](sql/setup.sql) in the Supabase SQL Editor.
2. Run [`sql/seed.sql`](sql/seed.sql) in the Supabase SQL Editor.
3. Copy the structure in [`config.example.js`](config.example.js) to
   `config.js` and enter only the project URL and public publishable/anon key.

The committed [`config.js`](config.js) contains the browser-safe configuration
used for verification. The deterministic seed can be regenerated from the CSV
with [`sql/build_seed.py`](sql/build_seed.py).

## 7. Evidence boundaries

StreetEasy describes advertised listings on its platform, not the rent paid by
every New Yorker. Dollar values are nominal and are not adjusted for inflation.
A visual or spatial association between rent growth, distance and accessibility
does not demonstrate that one caused another.

The 31 coordinates are representative points for StreetEasy reporting areas,
not official area boundaries or residential addresses. Marble Hill is retained
as a Manhattan rent-reporting area even though its representative point falls
just outside the dissolved Manhattan NTA geometry. See
[`../DATA_SOURCES.md`](../DATA_SOURCES.md) for the shared provenance and metric
definitions.
