# Mapping Systems weekly assignments — Ci Song

These assignments use one research question across the course:

> How did asking rents change across New York City from July 2016 to June
> 2026, and how do those changes relate to personal experience, spatial
> accessibility, and web infrastructure?

## Code-first boundary

- Assignments 01, 02, and 04 render their maps and charts from executable
  GeoPandas, Matplotlib, Lonboard, OSMnx, and NetworkX cells. The Notebooks do
  not read saved screenshots back into their outputs.
- Assignments 03 and 05 fetch GeoJSON or Supabase data and construct their map
  sources, layers, popups, filters, and interactions in JavaScript.
- This README does not embed exported map images. The two screenshot files
  below are retained only because the teacher explicitly requests one for each
  web-map submission. They are generated by the Playwright interaction test
  from the running pages, not used by either application at runtime:

  [Exercise 05 screenshot](05_web_map_visualization/outputs/web-map-supabase-desktop.png).

## Reproduce from a fresh clone

Use the Python environment created from the course `requirements.txt`. The
builders run with the same interpreter that invokes them; no Conda environment
or Jupyter kernel must be named `cdp`.

```bash
python shared/prepare_data.py

python 01_loading_and_visualizing_data/build_notebook.py

python 02_geoprocessing/scripts/process_personal_places.py
python 02_geoprocessing/build_notebook.py

python 03_networks/build_assignment.py

npm ci
python -m http.server 8005
```

With the local server running, open:

- <http://127.0.0.1:8005/04_web_mapping/>
- <http://127.0.0.1:8005/05_web_map_visualization/>

In a second terminal, exercise both pages and run the cross-assignment checks:

```bash
npm run test:web -- http://127.0.0.1:8005
python qa/validate_project.py
```

The full source definitions, transformations, and limitations are documented
in [DATA_SOURCES.md](DATA_SOURCES.md). Asking rent is an advertised-market
measure, not paid rent; dollar values are nominal; all accessibility and
inventory relationships are descriptive rather than causal.
