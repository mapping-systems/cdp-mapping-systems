# Data Notes

This folder contains the source snapshots and processed files used by the
notebook and public website. The generated 45 MB `manhattan_walk.graphml` file
is intentionally excluded from the course pull request to keep the repository
compact. It can be recreated from OpenStreetMap with the scripts in `../scripts/`.

The public application uses the smaller processed route and network files in
this folder and in `../site/data/`.
