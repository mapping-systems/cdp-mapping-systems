A Chrome HAR records every request made while a page loads. These points map the approximate IP locations behind one visit to Vanishing Network.

The map locates server and CDN IP labels. It does not locate the visitor, author, or subject of the website.

  4. 04
    Map

    Load the generated static GeoJSON as a Leaflet layer and group exact co-locations.

WHAT THE DATA CANNOT SAY

CDNs and anycast networks can make one IP appear at a database label or network edge rather than a single physical machine. The result is a snapshot of web infrastructure, not a route trace and not a map of people.
