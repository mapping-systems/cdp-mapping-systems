## Description: 

I chose the segment on the seatingchoice variable and color it categorically. I think this would help the user quickly identify the restaurants that provide a certain type of seating (e.g. sidewalk). Hovering over each of the markers also shows the restaurant name, the address, and the last date of inspection.

I chose a lighter map to bring attention to the pins and adjusted the icons to standards- a dot for the selected location and a pin icon for nearby restaurants. I also added in a low-opacity circle to delineate the search radius. Pin icons are lower in contrast/brightness while the selection dot is brighter.
