Where the course website travels.

A browser request feels instant, but it reaches servers and content delivery infrastructure in physical locations. This map geolocates the public server IPs recorded while visiting three course pages.

How to read it

Circle size represents captured request count. Select a point to inspect its IP, hosts, network organization, and approximate city.

What this cannot show

IP geolocation is approximate. A point may identify a CDN edge or cloud provider rather than the author, company headquarters, data center, or social origin of the page content.
