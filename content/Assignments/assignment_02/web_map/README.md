# Assignment 02 — 3D Dark Kitchen Rental Map

Interactive MapLibre map for Beijing.

- Color = median asking rent for delivery-oriented commercial space
- Height = number of high-confidence dark kitchens
- Basemap = CARTO Light / OpenStreetMap

Empty areas indicate missing rental observations, not zero rent or zero activity.

## Run
Open this folder in VS Code and use **Open with Live Server** on `index.html`.
