# NYC Cultural Organizations Map

This repository contains a Jupyter Notebook created for the **Loading and Visualizing Data** assignment.

The analysis uses the NYC Department of Cultural Affairs (DCLA) Cultural Organizations dataset to examine:

- the number and percentage of registered cultural organizations in each borough;
- the spatial distribution of major cultural disciplines across New York City.

## Files

- `Loading_And_Visualizing_Data_DCLA_Cultural_Organizations.ipynb` — complete analysis, visualizations, and reflections
- `DCLA_Cultural_Organizations.csv` — cultural organization records from NYC Open Data
- `NYC_Borough_Boundaries.geojson` — borough boundaries used as the map background

## Requirements

The notebook uses:

- pandas
- GeoPandas
- Matplotlib

Open the notebook in Jupyter and run the cells from top to bottom. Keep the CSV and GeoJSON files in the same folder as the notebook.

## Data sources

- [DCLA Cultural Organizations](https://data.cityofnewyork.us/d/u35m-9t32)
