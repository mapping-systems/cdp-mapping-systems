# Assignment 03 Web Map

Clean package for the Uber Eats HAR web mapping assignment.

## Files

- index.html
- style.css
- main.js
- data/ip_locations.geojson

## Run

Open this folder in VS Code, right-click `index.html`, then choose **Open with Live Server**.

The map:
- loads the supplied HAR GeoJSON;
- classifies requests by provider in JavaScript;
- colors points by provider;
- includes a legend;
- shows provider, IP, and request URL in a popup.
