# POPS-focused submissions: Assignments 01–04

These four submissions use one coherent subject—New York City Privately Owned Public Spaces—while preserving the distinct method required by each exercise.

| Assignment | Required method | Submission |
|---|---|---|
| 01 | Load, explore, and visualize a dataset; map and non-map views; limits | [`01_pops_data_exploration.ipynb`](01_pops_data_exploration.ipynb) |
| 02 | Personal narrative GeoJSON; related dataset; workflow diagram | [`02_pops_geoprocessing.md`](02_pops_geoprocessing.md), [`02_pops_research_mental_map.geojson`](02_pops_research_mental_map.geojson), [`02_pops_workflow.png`](02_pops_workflow.png) |
| 03 | HAR capture; geolocated request GeoJSON; runnable web map; screenshot | [`03_pops_har_web_map/`](03_pops_har_web_map/) |
| 04 | Define a network; compare Euclidean and network distance; maps, charts, reflection | [`04_pops_network_distance/`](04_pops_network_distance/) |

Assignment 02 uses 1211 Sixth Avenue as a confirmed daily-life anchor—frequent visits to a friend and occasional waiting outside—and explicitly distinguishes it from fourteen remotely researched comparison sites. Assignment 03 maps the web infrastructure used to load the POPS project, not the locations of plazas or users.
